1.19 Feature Engineering (Nuevas Variables)

Para reducir la correlación y encontrar mejores predictores, crearemos nuevas variables como el promedio de rendimiento de combustible y la relación peso-potencia.

# Promedio de rendimiento de combustible (ciudad y carretera)  1
df$avg_mpg <- (df$`city-mpg` + df$`highway-mpg`) / 2

# Relación peso-potencia (peso dividido por caballos de fuerza)
df$weight_power_ratio <- df$`curb-weight` / df$horsepower

# Verificamos la correlación con el precio
cor(df[, c("price", "avg_mpg", "weight_power_ratio")], use = "complete.obs")
##                         price    avg_mpg weight_power_ratio

## avg_mpg            -0.6842006  1.0000000          0.6120429
